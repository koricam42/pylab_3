# Lab 3 - Word Analyzer

Object-oriented, menu-driven Python program that reads text files, filters out punctuation, and generates an alphabetical word frequency report.

## Files Included

* `Lab10_koricam42-1.py`: Main program
* `requirements.txt`: Text file of dependancies 
* `princess_mars.txt`, `monte_cristo.txt``, `treasure_island.txt`, `Tarzan.txt`: Text files used for analysis
